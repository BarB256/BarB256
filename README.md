#### `> arena`
> Daily RPG tournament powered by GitHub followers.
Every day, my GitHub followers are thrown into a single-elimination bracket.
Stats are pulled from each player's public activity: - **Attack** Commits, PRs, issues, reviews - **Defense** Followers + public repos - **HP** Total contributions - **Crit** Contribution volume - **Super** Activity evenness across channels; Two fighters take turns swinging. Damage = attacker's ATK minus a slice of the defender's DEF, with random variance. Critical hits hit 1.6x harder. Super attacks trigger based on how evenly a player spreads their activity across commits, PRs, issues, and reviews — well-rounded developers hit harder
